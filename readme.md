# 🏥 Healthcare Data Analysis

This project explores and analyzes a healthcare dataset to uncover insights about patients, hospitals, medical conditions, and billing.  
It uses **Python, Pandas, Matplotlib, and Seaborn** for data analysis and visualization.

---

## 📂 Dataset
- Source: [Kaggle Healthcare Dataset](https://www.kaggle.com/datasets/prasad22/healthcare-dataset)  
- Format: CSV (`healthcare_dataset.csv`)  
- Size: ~8 MB  
- Key Columns:
  - `Name`, `Age`, `Gender`, `Blood Type`
  - `Medical Condition`, `Date of Admission`, `Discharge Date`
  - `Doctor`, `Hospital`, `Room Number`
  - `Insurance Provider`, `Billing Amount`
  - `Admission Type`, `Medication`, `Test Results`
